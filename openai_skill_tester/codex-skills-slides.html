Codex Skills

Adding Skills to Codex

Manual authoring first. Shared and community skills second.

HTML slide deck

What a skill is

  • Reusable instructions for a repeatable Codex workflow
  • A small directory with one required SKILL.md
  • Optional scripts/, references/, and assets/
  • Loaded only when the task matches the skill

Create the folder

my-skill/ my-skill/SKILL.md my-skill/references/optional-notes.md my-skill/scripts/optional-helper.py my-skill/assets/optional-template.html

Write the manifest

---
name: release-helper
description: Use when preparing a release checklist, changelog, or release PR.
---

# Release Helper

Follow the repository release checklist.
Read references/release-process.md before editing files.
Run the verification command listed in package.json.

Put it where Codex can see it

Repo skills

.agents/skills inside the current folder or repo root. Best for team workflows checked into source control.

User skills

$HOME/.agents/skills. Best for personal workflows you want across repositories.

Make manual skills reliable

  • Keep one skill focused on one job
  • Front-load trigger words in the description
  • Prefer instructions until scripts are truly useful
  • Restart Codex if a new skill does not appear

Install curated skills

  • Use $skill-installer for curated local additions
  • Name the skill you want: $skill-installer linear
  • Let Codex place it in your local skill library
  • Use /skills or $ to confirm it is available

Install from another repo

  • Point $skill-installer at the source repository
  • Review the skill instructions before relying on them
  • Check optional scripts for commands, network use, and file edits
  • Restart Codex if the installed skill is missing

Share with plugins

  • Use direct skill folders for local authoring
  • Package reusable skills as plugins for distribution
  • Bundle multiple skills, app mappings, MCP setup, or assets
  • Keep repo-specific skills in the repo when the workflow belongs there

Summary

Build once. Reuse often.

Manual Create a folder, write SKILL.md, put it in a scanned location.
Installed Use $skill-installer for curated skills or skills from other repos.
Distributed Use plugins when a skill should travel cleanly to other developers.

Source basis: OpenAI Codex Agent Skills documentation and Codex reusable skills guidance.
