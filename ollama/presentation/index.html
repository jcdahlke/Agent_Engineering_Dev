What is Ollama?

A runtime for local language models

✦
Local Inference
Models run entirely on your machine — no API calls, no latency surprises, no per-token fees.
Privacy First
Your prompts and data never leave your device. Ideal for sensitive research data.
Works Offline
Once models are pulled, the server runs without any internet connection whatsoever.
Open Source
Free forever. Hundreds of models on ollama.com/library — Llama, Mistral, Phi, Gemma, and more.

Setup

Installing Ollama

1
Download Ollama
Visit ollama.com/download — native installers for Windows, macOS & Linux. No dependencies required.
2
Verify Installation
Open a terminal and confirm Ollama is on your PATH.
$ ollama --version → ollama version 0.x.x
3
Server Starts Automatically
Ollama launches a local REST API at http://localhost:11434 — no extra configuration needed.

Strengths

What Ollama Does Well

  • ✓
    Complete Privacy
    Runs entirely on your machine — prompts and data never reach an external server.
  • ✓
    Free Inference
    No API costs, no usage limits, no rate throttling — run as many evaluations as you need.
  • ✓
    Works Offline
    Perfect for air-gapped environments, travel, or unreliable internet.
  • ✓
    Easy Model Switching
    One line in OLLAMA_MODELS swaps the entire model — re-run the benchmark in minutes.
  • ✓
    Vast Model Library
    Hundreds of models on ollama.com/library — Llama, Mistral, Phi, Gemma, Qwen, and more.

Limitations

Limitations to Know

  • ✗
    Hardware Requirements
    8 GB+ RAM for small models; 16 GB+ for Mistral and Gemma. GPU acceleration (CUDA/Metal) is strongly recommended.
  • ✗
    Capability Gap
    Local 7B–13B models consistently lag behind GPT-4o on complex reasoning and nuanced classification tasks.
  • ✗
    Large Downloads
    Each model is 2–5 GB — all four benchmark models together require ~13 GB of disk space.
  • ✗
    Slower Cold Start
    First inference after loading a model is noticeably slower than cloud APIs; expect several seconds before the first token.
